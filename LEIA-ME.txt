===========================================================
COMO PUBLICAR NO GITHUB PAGES
===========================================================
1) github.com  ->  botao "+" (canto superior direito)  ->  New repository
   Nome:      ensino-policial-pmrr
   Visibilidade: Public   (no plano gratuito o Pages so funciona em publico)
   NAO marque "Add a README file"
   ->  Create repository

2) Na tela que abrir, clique em "uploading an existing file".
   Arraste PARA A JANELA DO NAVEGADOR:
      - index.html
      - capa.png
      - a pasta midia inteira
   Espere as 8 barrinhas chegarem a 100%.
   ->  Commit changes

3) Aba Settings  ->  menu da esquerda, Pages
   Source: Deploy from a branch
   Branch: main   /  (root)
   ->  Save

4) Espere 1 a 2 minutos e recarregue a pagina Settings > Pages.
   Vai aparecer o endereco:
   https://SEU-USUARIO.github.io/ensino-policial-pmrr/
